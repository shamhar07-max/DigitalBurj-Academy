# Curriculum map

129 courses, five named modules per course and 1290 authored project recipes. Every recipe follows Understand → Explain → Build → Test & fix → Reflect → Submit. Practice times are estimates; independent subject approval is required for assessed delivery.

The original 48 programmes and 192 missions are preserved and mapped to course access. 111 subject-area courses merge near-duplicate programme variants into one course each and are standalone: they have no mapped professional programme and use fictional practice cases only. Their alignment records are in content/source/iisdt-syllabi.json.
