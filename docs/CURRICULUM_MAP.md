# Curriculum map

18 courses, five named modules per course and 180 authored project recipes. Every recipe follows Understand → Explain → Build → Test & fix → Reflect → Submit. Practice times are estimates; independent subject approval is required for assessed delivery.

The original 48 programmes and 192 missions are preserved and mapped to course access.
