# Standard Academy release

1 October 2026. This extends the existing DigitalBurj Academy and retains its exact repository logo and font assets. GitHub is read-only. The hosted edition retains owner-private sharing. Native ChatGPT identity supports registration; live merchants, staffing and domain setup still require their actual configuration. See ACCESS_REGISTRATION_FIX.md for the latest mandatory registration gate.

Free courses skip purchase. Hosted preview flags cannot bypass registration or serve the full private curriculum. Controlled local test fixtures do not grant live entitlements or staff roles. The original Professional Practice Workspace sits inside the same Academy shell, with all 48 programmes, 192 missions, twelve original mission stages, tools, guidance and evidence workflows retained. Connected access to its programme content follows the mapped course entitlements and staff scope.

Older course URLs enter the dedicated dashboard's course list. The standalone practice-library URL enters the integrated Professional Practice Workspace. The owner console requires registered owner access and closes on account switching, sign-out and browser-history restoration.

Eleven included tools: Writing desk, Web studio, Data desk, Prompt studio, Automation lab, API trainer, Design desk, Project board, Budget calculator, JSON inspector and Contrast checker. Work persists in the relevant browser/account namespace; students can export their actual output. HTML executes inside a sandbox without same-origin privileges. ## Dedicated teaching

A supported package contains eight weeks, 24 individual classes, three classes per week, two hours per class: 48 hours total. An appointed, currently qualified course mentor must exist before enrolment is offered. After confirmed payment, the owner assigns a real teacher and agreed teaching period. That period must fit inside the order's active course access.

Students save days/times/timezone preferences and book only offered times for their teacher, course and teaching period. Transactional checks enforce 24 total classes, three per package week and no overlapping bookings. Meeting links support HTTPS Google Meet, Zoom and Microsoft Teams. Completed attendance is recorded after the two-hour class ends, by the assigned qualified teacher or owner. Cancellation releases future times. Full refund or dispute suspends the package, cancels future booked classes, releases times and hides meeting links. Meeting services require their own real accounts; this release does not host video calls.

## Payment integrations

Stripe Checkout Elements provides provider-owned card fields and eligible wallets, including Google Pay when the device, region and merchant support it. Academy JavaScript cannot read card number or CVC. The animated live card reacts to method/completion. A separately labelled visual sample mirrors only fictional Stripe test digits, flips for sample CVC and makes no request, charge or access grant.

Gumroad requires an approved USD product, merchant credentials, seller ID and a same-email purchase claim. The authenticated sale lookup must match the stored product, amount, currency and merchant. A paid one-off purchase must also appear in Gumroad's successful Sales list; failed/test/free/subscription records do not fulfil access. A unique provider/reference constraint prevents reusing a purchase.

Binance Pay uses signed merchant requests, stores the accepted crypto quote for the fiat order and verifies the authenticated order query. Signed RSA callbacks trigger reconciliation. Other approved wallet networks use NOWPayments: a signed IPN triggers an authenticated payment query; only a fully paid `finished` record fulfils access. Pending, confirmed and partial transfers grant nothing. No user-supplied wallet transaction hash unlocks a course.

All providers remain disabled until merchant configuration and an approved product are present. Real checkout and refund testing on the deployment is still required. Receipt amounts record the matched Academy order; vendor receipts govern provider fees, buyer-currency conversion and tax details. Academy acknowledgements are not tax invoices.
