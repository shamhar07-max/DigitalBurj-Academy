# Included feature inventory

This inventory describes the features included in the deployable source. Production data is created by real registered users and confirmed provider actions.

| Area | Included behaviour | Required service or owner action |
| --- | --- | --- |
| Account entry | Sign-in/register/recovery, token confirmation and consented profile | Supabase Auth, SMTP and exact email templates |
| Sessions | Secure HttpOnly cookie, encrypted tokens, expiry, password change and logout | Stable session key and persistent database |
| Access | Anonymous content blocked; free foundations; exact purchased/assigned scope | Approved purchases or owner appointment |
| Owner | Administration, offers, merchant connection, appointments and suspension | Verified matching owner email |
| Demo | All 129 guided courses and 48 professional programmes until expiry | Real demo email appointed by owner |
| Teachers | Six appointments, scoped courses and teaching operations | Real emails, checked qualifications and current access |
| Guided learning | 1,290 projects, explanations, task checks, typed/dictated understanding and evidence | Learner account and course access |
| Professional Practice | Original 48 programmes, 192 missions, 576 units and all 14 sections | Relevant free/purchased/assigned programme access |
| Plan | Guided/Professional route, course/programme, days, hours and timezone, cloud save | Registered account |
| Tools | Writing, web/data/prompt/automation/API practice, design desk, project board, budget, JSON and contrast tools | Registered account; training simulations are labelled |
| External directory | Free/Freemium/Paid links and tool icons | Provider's own account/subscription when applicable |
| Drafts and snapshots | Device-local drafts/export; explicit versioned cloud snapshots | Save cloud snapshots deliberately for cross-device work |
| Activity | Actual saves, submissions, payments and class operations | Genuine actions; views are not grades or attendance |
| Guide | 15 chapters, glossary, route and role instructions | Registered account |
| INR checkout | Approved Razorpay offers and provider-hosted protected payment fields | Eligible live merchant, actual prices and signed webhook |
| Other merchants | Stripe/Gumroad/Binance Pay/NOWPayments adapters and order reconciliation | Eligible accounts and adapter-specific offers |
| Card visual | Animated fictional Visa/Mastercard-style input sample | Actual card number/CVC is collected by the payment provider |
| Receipt | Stored payment acknowledgement and animated printing | Confirmed capture; business supplies tax invoices |
| Refund/dispute | Signed reconciliation, idempotence and access withdrawal | Merchant-dashboard action and matching notifications |
| Private teaching | Eight weeks, 24 two-hour classes, three per week, availability and booking checks | Paid package, qualified teacher and real meeting links |
| Attendance | Post-class completion notes and cancellation controls | Actual teaching recorded by the assigned teacher |
| Assessment | Evidence, reviewer scope, separate verifier, feedback and appeals | Qualified staff and learner evidence |
| Certificate | Issued record, QR, barcode, print/export, public lookup and revocation | Independent assessment; samples are not issued qualifications |
| Data | Durable libSQL, atomic write batches and checksum migrations | Hosted database and protected token |
| Operations | Readiness, no-store responses, graceful Node shutdown and host configuration | Host monitoring and database backups |

There is no 3D-printer tool. The printing effect is the purchase receipt animation.

External model subscriptions, automatic AI API calls, live business automation executions, video-call infrastructure and provider merchant approvals are not bundled as hidden services. Practice tools and external links are included; the teaching team supplies actual meetings and qualified review.
